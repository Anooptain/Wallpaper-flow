## Features

- Automatic wallpaper changing
- Custom wallpaper schedules
- Online wallpaper discovery
- AI wallpaper generation
- Import photos from gallery
- Home Screen and Lock Screen support
- Wallpaper preview and favorites
- Offline wallpaper support
- Battery optimization settings
- Automatic scheduling after device restart
